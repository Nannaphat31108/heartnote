# เติมพลังใจครู (HeartNote)

เว็บไซต์โปรแกรมส่งเสริมสุขภาวะทางอารมณ์ด้วยการ์ดคำถามสะท้อนตนเองในรูปแบบออนไลน์
สำหรับนักศึกษาวิชาชีพครูชั้นปีที่ 1

## ฟีเจอร์
- 4 หมวดคำถาม หมวดละ 25 ข้อ (รวม 100 ข้อ) — แก้ไขได้ที่ `js/questions.js`
- สุ่มการ์ดแบบไพ่ดูดวง: สับไพ่ เลือกการ์ดที่ใจเรียก แล้วพลิกเปิดพร้อมคำอวยพร
- ไม่สุ่มคำถามซ้ำในหมวดเดิมจนกว่าจะครบ 25 ข้อ
- ตอบคำถามบนการ์ด + คำถามสะท้อนตนเองเพิ่มเติมอีก 1 ข้อ + เลือกความรู้สึกหลังทำกิจกรรม
- หน้าบันทึกและความก้าวหน้า (8 สัปดาห์ × 5 ครั้ง = 40 ครั้ง) และดาวน์โหลดบันทึกเป็น CSV

## การใช้งาน
เป็นเว็บแบบ static (HTML/CSS/JS) ไม่ต้องติดตั้งอะไร
- เปิดในเครื่อง: `python3 -m http.server` แล้วเข้า http://localhost:8000
- เผยแพร่ออนไลน์: เปิด GitHub Pages ที่ Settings → Pages → Deploy from branch

> หมายเหตุ: บัญชีผู้ใช้และบันทึกเก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง
> (ไม่มีเซิร์ฟเวอร์กลาง) หากต้องการเก็บข้อมูลรวมเพื่อการวิจัย ต้องต่อฐานข้อมูลเพิ่มเติม
